Claims agent loop

A hand-rolled ReAct loop — plan, act, observe, repeat — next to a fixed claims checklist. The loop is ~50 lines. Frameworks like LangChain/LangGraph wrap the same thing.

Open Chat (one-shot RAG)
How to test this (mentor checklist)
  1. Upload the four sample PDFs on Documents and wait until they are Processed.
  2. Stay on this page. Pick Full investigation (branching), mode Agent loop, click Run. You should see several steps: thought → tool → observation, then a final answer. That is a genuine multi-step task.
  3. Set Max steps to 2 and run the same task again. It must stop with “max steps” instead of looping forever.
  4. Pick Known checklist or Single fact, mode Race both. Compare LLM calls, time, and tokens. Read the What I’d ship card — that is the workflow-vs-agent decision with real numbers.
  5. After a finished investigation, pick Follow-up (memory) with the same session id. The agent should call search_memory (or inject prior notes) instead of starting from zero.
