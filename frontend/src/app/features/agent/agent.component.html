How to test this (mentor checklist)
  1. Confirm the agent uses a tool discovered over MCP (not a hard-coded list). Pick MCP tool (file status) and run — you should see document_status in the handshake and in the step timeline.
  2. Add a second tool without changing the agent loop: put @mcp.tool on a new function in backend/app/mcp/claims_server.py, restart, click Rediscover. It should appear in the tool list.
  3. Another person’s agent can call this server at http://localhost:8000/mcp with Authorization: Bearer from MCP_AUTH_TOKEN, or via stdio: python -m app.mcp.
  4. The AI runs on the host (this app + Ollama). It does not run on the MCP server. The server does not know which model called it.
