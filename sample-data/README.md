# Sample Insurance Documents

These files are demo claim artifacts for local testing.

Upload them through the Angular **Documents** page. Do not embed their contents into application code.

Suggested first upload:

1. `claim-investigation-report.pdf`
2. `damage-assessment-report.pdf`
3. `policy-schedule.pdf`
4. `claim-settlement-letter.pdf`

Week 8 prompt-injection drill (optional extra file):

5. `injected-adjuster-notes.txt` — looks like a real desk-review note, but contains a hidden instruction that tries to hijack the agent. Upload it, then on **Agent** pick **Poisoned document**.

Then ask in Chat:

- What was the cause of the loss?
- What is the estimated repair cost?
- What deductible applies?
- What is the net settlement amount?
